# Diplom_2
## Описание проекта
Этот проект — дипломная работа по автоматизации тестирования API для сервиса Stellar Burgers. Он проверяет основные функции приложения, такие как регистрация пользователей, авторизация и создание заказов. Проект написан на Java и использует современные инструменты для удобного запуска и отчётности.

### Технологии

* Java 11 — основной язык программирования.
* JUnit 4 — для написания и запуска тестов.
* REST Assured — для тестирования REST API.
* Allure — для генерации красивых отчётов о тестах.
* Maven — для управления зависимостями и сборки проекта.
* Lombok — для упрощения кода моделей.

### Как запустить
1) Убедитесь, что у вас установлены Java 11 и Maven.
2) Клонируйте репозиторий: git clone <ссылка на репозиторий>.
3) Перейдите в папку проекта: cd Diplom_2.
4) Запустите тесты: mvn test.
5) Посмотрите отчёт: mvn allure:serve (откроется в браузере).
